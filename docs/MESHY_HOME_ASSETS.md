# Meshy home assets

These prompts are for the procedural-to-GLB replacement hooks in the home scene.

## Shared direction

Use a cohesive stylized Turkish village-house look: warm hand-painted realism, slightly simplified shapes, readable from a third-person camera, no logos, no text, no background scene. Generate each object as a single game prop. Use Smart Topology / low-poly, clean topology, about 500–2,000 polygons for ordinary props, UV unwrapped, PBR texture, export GLB.

## Export / integration

For this Three.js game, export **GLB**. Meshy's documentation recommends GLB for web/Three.js assets, and its game-asset workflow supports remeshing and PBR texturing before export. Keep the generated object centered and close to real-world scale; the code's `PropFactory` will fit it to the existing procedural placeholder.
